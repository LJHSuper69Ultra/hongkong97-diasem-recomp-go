# 동작 원리

## 재컴파일된 코드 (`recomp/`)

- `gen.go`는 원본 명령어 하나를 `switch`의 `case` 하나로 만든 Go 코드입니다. 각 `case`의 주석에 원래 SNES 주소와 기계어가 적혀 있습니다.
- 레지스터(A, X, Y, S, D, DB, PB, P)와 M/X 폭 처리는 `machine.go`의 런타임이 맡습니다.
- 메모리, PPU 레지스터, DMA는 `hw/`가 맡습니다.
- 원본이 vblank를 기다리는 지점(`$80:83D6`)에서 런타임이 프레임을 호스트에 넘깁니다. 이어서 원본 NMI 핸들러(`$80:83DC`)를 실행합니다.
- 자원을 가리키는 코드 피연산자 148곳은 숫자 대신 `m.rel16(i)` 등으로 생성되어 있습니다. 시작할 때 `romdatasyms.json`(빌드가 정한 자원 주소)으로 확정됩니다.
- 코드가 데이터처럼 읽는 코드 주소 표(오브젝트 핸들러 표)는 `codeData`로 생성 코드에 들어 있습니다.

## 확장 (`recomp/ext.go`, `recomp/korean.go`)

- 원본에 없는 기능(한국어)은 생성 코드를 고치지 않고 확장으로 붙입니다.
- 재컴파일러는 점프 테이블(`JMP (표,X)`)의 `switch`에서 원본 표에 없는 번호를 `m.jumpExt(표 주소)`로 넘깁니다.
- 확장은 (표 주소, X)에 처리 함수를 등록합니다. 처리 함수는 흉내 낼 원본 코드처럼 레지스터를 맞추고, 이어서 실행할 주소를 돌려줍니다.
- 확장만 쓰는 자원(한국어 대사)은 `m.asset(이름)`으로 `tools/pack`이 정한 주소를 얻습니다.

## 데이터 이미지 (`tools/pack`)

1. `manifest.json`의 항목을 형식별로 인코딩합니다. 압축 형식은 `assetfmt/lz.go`의 압축기로 압축합니다.
2. 원래 자리에 들어가면 그대로 둡니다.
3. 넘치면 코드가 쓰던 영역(`recomp/codemap.txt`)과 다른 자원을 피해 빈 곳에 배치합니다.
4. 결과는 512KB 주소 공간 이미지입니다. 코드 영역은 비어 있습니다.

## 압축 형식 (원본 `$80:9DA6`)

- 처음 2바이트는 풀린 크기입니다.
- 그 뒤로 명령 바이트의 상위 비트에 따라 백레퍼런스 4종과 리터럴 2종이 이어집니다.
- 자세한 비트 배치는 `assetfmt/lz.go` 상단 주석에 있습니다.

## 검증 도구

- **`cmd/oracle`**: 65816 인터프리터와 PPU로 원본 ROM을 그대로 실행해 프레임을 PNG로 저장합니다. 자동 플레이 봇을 지원합니다.
- **`cmd/compare`**: 원본 실행과 이 빌드를 논리 프레임(`$80:83C3` 진입) 단위로 맞춰 돌리며 WRAM, VRAM, CGRAM, OAM을 비교합니다.
  - 예: `go run ./cmd/compare -rom 원본.sfc -data cmd/hk97/romdata.bin -syms cmd/hk97/romdatasyms.json -n 9000 -in "130:0400,138:0,150:0400,158:0,170:0080,178:0" -bot 300 -god 7000 -ignore "1E00-1FFF,9F,A0,A8,00-0F,29-2D"`
- **`tools/pack -verify 원본.sfc`**: 자원을 고치지 않은 상태에서 데이터 바이트가 원본과 같은지 확인합니다.

## 사운드 (`apu/`)

- **SPC700:** `spc700.go`는 사운드 CPU 명령 256개 전부와 사이클 수를 구현합니다.
- **입출력:** `apu.go`가 맡습니다.
  - I/O 레지스터 `$F0-$FF`(DSP 포트, 타이머 3개, CPU 포트 4개)
  - 32kHz 샘플 클록
  - 부팅 업로드 프로토콜
- **DSP:** `dsp.go`가 S-DSP를 구현합니다.
  - BRR 필터 4종
  - 가우스 보간(하드웨어 상수표 `gauss.go`)
  - 엔벨로프(공용 카운터 레이트 표)
  - KON/KOFF 2샘플 주기
  - 노이즈, 피치 변조, 에코
- **실행 흐름:** 게임 코드가 vblank를 기다릴 때마다 사운드 CPU를 1/60초만큼 실행합니다. 나온 32kHz 샘플은 `cmd/hk97/sound.go`가 48kHz로 바꿔 재생합니다.
- **대기 루프 처리:** 게임 CPU가 사운드 포트를 반복해서 읽으며 기다리는 동안에는, 읽을 때마다 사운드 CPU를 조금씩 진행시킵니다.
